# eTicaretSolution
 Siliconmade uzmanlık eğitimindeki onuncu projem: ASP.NET Core MVC ile geliştirilen e-Ticaret sitesi (eTicaretMVC) ve yönetim paneli (AdminMVC). Ogani ve SB Admin 2 şablonları kullanılarak responsive arayüzler oluşturuldu; CRUD işlemleri, özel route yapıları ve Razor view’lar implemente edildi.
